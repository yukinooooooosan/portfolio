家族共有カレンダーアプリについて
PRIVACY POLICY

プライバシーポリシー

制定日：2026年10月13日

家族共有カレンダー は、家族が共有する Google カレンダーの予定管理を目的とした、家族専用アプリです。

1. アクセスする情報

利用者が許可した Google カレンダーについて、カレンダーの識別情報、予定のタイトル、日時、場所、説明など、予定の確認・追加・変更に必要な情報にアクセスします。Google との連携に必要な認証情報も取り扱います。

2. 利用目的

Google カレンダー情報は、家族の予定を表示し、家族による予定の追加・変更を反映するために使用します。家族用の機能の提供・運用以外の目的や、広告目的には利用しません。

3. 家族以外への共有

取得したカレンダー情報を家族以外の第三者に共有・販売しません。利用者の操作に基づく予定の更新には、Google カレンダー API を使用します。

4. 情報の管理

カレンダー情報と連携に必要な認証情報は、家族の運用担当者が管理します。情報の取り扱いや保管された情報の削除については、運用担当者にお問い合わせください。

5. 連携の解除

利用者は、Google アカウントのサードパーティとの接続設定から、家族共有カレンダー に与えたアクセス権を取り消せます。連携解除と、運用環境に保管された情報の削除は別の手続きです。

6. Google API の利用

家族共有カレンダー による Google API から取得した情報の使用は、Limited Use 要件を含むGoogle API Services User Data Policyに従います。

7. お問い合わせと変更

お問い合わせは、家族内の 家族共有カレンダー 運用担当者にお願いします。情報の取り扱いが変わる場合は、このページを更新します。
